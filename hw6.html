Riemann, Lebesgue and the normal CDF

Exercise 1 approximates integrals in two ways, by partitioning the domain as in Riemann's definition and by partitioning the range as in Lebesgue's, and compares them. Exercise 2 computes the cumulative distribution function of the standard normal distribution, which has no elementary closed form.

1 Riemann and Lebesgue sums

  • Riemann: partition the domain. [a, b] is cut into N subintervals of width h = (b − a)/N and f is evaluated at the midpoint of each: ∫f ≈ h·Σᵢ f(a + (i + ½)h).
  • Lebesgue: partition the range. The values of f, from y_min to y_max, are cut into K levels tⱼ, and for each level the measure of the preimage {x : f(x) > tⱼ} is taken: ∫f = y_min·(b − a) + ∫ μ({f > t}) dt ≈ y_min·(b − a) + Δt·Σⱼ μ({f > tⱼ}). A computer cannot measure a preimage exactly, so μ is estimated from M = N points of the domain: the values are sorted once and, for each level, a binary search counts how many exceed tⱼ.

For all these Riemann-integrable functions the two approaches converge to the same value, the exact integral. The two step functions are computed exactly by both, up to rounding, when N is even, because the jump at 0.5 falls on the border between two subintervals; with N odd the subinterval containing 0.5 gives a Riemann error of order 1/N. For 1/√x the integral is improper in Riemann's sense, and both sums converge only slowly.

  • Accuracy and convergence. For smooth functions the midpoint Riemann error falls like 1/N²: a factor 100 for every factor 10 in N. The Lebesgue error falls more slowly and less regularly, because it has two sources: the K levels, and the estimate of each preimage measure from a finite number of points, which changes in steps of 1/M. For |x − 0.5| the midpoint rule is exact, because f is linear on each subinterval. For 1/√x both errors fall only like 1/√N, because of the singularity at 0.
  • Where Lebesgue is natural. For a step function the measure of {f > t} is the same for every level between the two values, so the range partition captures it with any K; the Riemann sum needs the jump to fall on a border.
  • Efficiency. The Riemann sum costs N evaluations and N additions. The Lebesgue sum costs the same N evaluations plus sorting them, O(N log N), and K binary searches, O(K log N), so it is several times slower for the same N.

3 Where the two approaches differ

Dirichlet function

f(x) = 1 if x is rational, 0 otherwise. Every subinterval, however small, contains both rationals and irrationals, so the upper Darboux sum is 1 and the lower is 0 for every partition: the Riemann sums depend on the points chosen and f is not Riemann-integrable. Lebesgue's definition partitions the range {0, 1}: the preimage of 1 is ℚ ∩ [0, 1], which is countable, so it has measure 0, and the preimage of 0 has measure 1. Hence ∫f = 1·0 + 0·1 = 0. That ℚ ∩ [0, 1] has measure 0 can be checked numerically: listing the rationals and covering the k-th with an interval of length ε/2ᵏ, the total length of the cover never exceeds ε, however many rationals are covered.

A numerical sampling cannot do this directly: every floating-point number is a fraction with a power of 2 in the denominator, so a program that evaluates f at sample points would find f = 1 everywhere.

Thomae's function

f(p/q) = 1/q in lowest terms, 0 at irrationals. The lower Darboux sum is 0, because every subinterval contains irrationals. The supremum on a subinterval is 1/q, with q the smallest denominator of a rational inside it; computing it exactly gives the upper sums below, which go to 0, so f is Riemann-integrable with integral 0. For Lebesgue, f = 0 except on the countable set of rationals, which has measure 0, so the integral is again 0: here the two approaches agree.
